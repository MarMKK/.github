# Märjamaa Muusika- ja Kunstikool

Märjamaa Muusika- ja Kunstikool (MMKK) on Märjamaa valla huvikool, mis pakub süsteemset muusika- ja kunstiharidust lastele ja noortele. Kooli eesmärk on avastada ja arendada õppurite andeid, valmistada soovijaid ette edasiõppimiseks ning pakkuda sisukat huvitegevust kõigile, kes muusikat või kunsti armastavad.

Märjamaa Muusika- ja Kunstikooli eesmärgiks on olla avatud (halvale suletud), sõbralikuks (kuid nõudlikuks) ja targaks (ning ettenägelikuks) kultuurikeskuseks, kus on mitmekesised võimalused loominguks.
